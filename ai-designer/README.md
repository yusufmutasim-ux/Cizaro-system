# Studio AI — مصمم الإعلانات

ويب ابلكيشن بيشتغل كفريق كرييتيف كامل: آرت دايركتور + جرافيك ديزاينر + كوبي رايتر + ميديا باير.
تطلب منه أي إعلان أو بوست أو صورة أو كامبين كاملة، وهو يعمله **ملتزم بهوية البراند** بالظبط.

## بيعمل إيه

- **كل براند في تاب لوحده** فوق، وكل براند ليه:
  - **البراند بوك**: التاجلاين، الجمهور، نبرة الكلام، اللغة واللهجة، الألوان (بدورها: أساسي/ثانوي/خلفية…)، الخطوط، ستايل الصور، قواعد اللوجو واللاي أوت، «دايماً» و«ممنوع»، المنافسين.
  - **ملفات**: اللوجو، صور المنتجات، مراجع الستايل، ملفات الخطوط، والجايدلاين.
  - **املاه أوتوماتيك**: ارفع الجايدلاين (PDF أو صور) والمصمم يملا البراند بوك كله، وانت تراجع وتحفظ.
- **الاستوديو**: شات مع المصمم. اكتب البريف (أو اختار «إعلان سوشيال»، «كامبين كاملة»، «ستوري»، «3 أفكار A/B»…) وأرفق صور المنتج لو عايز.
  المصمم بيفكر في الفكرة، يكتب الكوبي بلهجة البراند، يولّد الصورة على **Higgsfield** عن طريق الـ MCP، ويسلّمك التصاميم جاهزة.
- **التصميم النهائي بيتركّب جوه التطبيق**: الصورة بتتولد من غير كلام، والتطبيق بيحط العنوان والـ CTA و**اللوجو الحقيقي** بخطوط البراند وألوانه
  (عشان العربي يطلع مظبوط والهوية تفضل ثابتة). من المحرر تقدر تعدّل النص، مكانه، الألوان (من باليتة البراند بس)، مكان اللوجو، والمقاس (1:1، 4:5، 9:16، 16:9)، وتحمّل PNG.
- **مراجعة البراند**: زرار بيراجع التصميم النهائي قصاد البراند بوك ويديله درجة من 100 مع ملاحظات وتعديلات مقترحة.
- **الكامبينز**: الفكرة الكبيرة، الرسالة، الهدف، الجمهور والاستهداف، المنصات، التايم لاين، توزيع الميزانية، الـ KPIs، ومجموعة الإعلانات كلها متناسقة.
- **المكتبة**: كل التصاميم والكامبينز محفوظة لكل براند، بالمفضلة والفلاتر، والكابشن والهاشتاجات جاهزين للنسخ.
- **«اطلب تعديل»** على أي تصميم يرجعك للمحادثة والمصمم يعدّله.

## إزاي بيشتغل

| الجزء | بيعمل إيه |
|---|---|
| **Claude** (`claude-opus-5-5`) | المخ: الفكرة، الكوبي، الإخراج الفني، الالتزام بالبراند بوك، ومراجعة الشغل |
| **Higgsfield MCP** | توليد الصور. Claude بيتصل بيه مباشرة عن طريق MCP connector ويختار الموديل والمقاس ويتابع التوليد لحد ما الصورة تخلص |
| **التطبيق** | بيحفظ الصور، يركّب الإعلان النهائي بخطوط وألوان ولوجو البراند، ويخزن كل حاجة |

البراند بوك بيتبعت للمصمم مع كل طلب كقواعد ملزمة، والمصمم بيبص على الصور اللي اتولدت ويعيد أي واحدة خارجة عن الهوية قبل ما يسلّم.

## التشغيل

محتاج Node.js 20+.

```bash
cd ai-designer
npm install
cp .env.example .env      # حط ANTHROPIC_API_KEY و SESSION_SECRET
npm run setup             # بيعمل قاعدة البيانات
npm run dev               # http://localhost:3000
```

وبعدين من **الإعدادات** (أيقونة الترس) حط:

1. **Claude API Key** — من console.anthropic.com.
2. **رابط Higgsfield MCP** و **التوكن** — من حسابك على Higgsfield. بعدها دوس «جرّب الاتصال» وهيظهرلك أدوات التوليد اللي لقاها.
3. **APP_URL** (لما يكون مرفوع على سيرفر) — عشان Higgsfield يقدر يستخدم اللوجو وصور المنتجات كمرجع وهو بيولّد.

أي قيمة من دول ممكن تتحط في متغيرات السيرفر بدل الإعدادات (`ANTHROPIC_API_KEY`، `HIGGSFIELD_MCP_URL`، `HIGGSFIELD_MCP_TOKEN`، `APP_URL`).
لو Higgsfield مش متوصل، المصمم بيسلّم التصميم بالكوبي وبرومبت الصورة، وتقدر تولّدها بنفسك وترفعها على التصميم.

> **مهم:** لو هتفتحه على الإنترنت حط `APP_PASSWORD` عشان محدش يستخدم مفتاح Claude بتاعك.

## الرفع على Railway

1. **New Project ← Deploy from GitHub repo**، واختار الريبو، وفي **Settings ← Root Directory** اكتب `ai-designer`.
2. في **Variables** ضيف: `ANTHROPIC_API_KEY`، `SESSION_SECRET` (نص عشوائي طويل)، `APP_PASSWORD`، و`APP_URL` (رابط الدومين)، واختيارياً `HIGGSFIELD_MCP_URL` و`HIGGSFIELD_MCP_TOKEN`.
3. **Attach Volume** على `/data` (هنا قاعدة البيانات والصور، من غيره بيتمسحوا مع كل deploy).
4. **Settings ← Networking ← Generate Domain**.

أو بـ Docker على أي سيرفر:

```bash
docker build -t studio-ai .
docker run -d -p 3000:3000 --env-file .env -v studio-data:/data studio-ai
```

## التقنيات

Next.js 15 · React 19 · Prisma + SQLite · Claude API (`@anthropic-ai/sdk`، MCP connector، structured outputs) · sharp · Canvas لتركيب الإعلانات.

```
src/lib/designer.ts      المصمم: التعليمات، أداة present_designs، الاتصال بـ Higgsfield MCP، ولوب المحادثة
src/lib/brand.ts         البراند بوك وإزاي بيتحول لقواعد للمصمم
src/lib/review.ts        ملء البراند بوك من الجايدلاين، ومراجعة التصميم
src/lib/compose.ts       تركيب الإعلان النهائي (الصورة + النص + اللوجو بخطوط البراند)
src/components/          الاستوديو، المحرر، المكتبة، البراند بوك، الإعدادات
```
